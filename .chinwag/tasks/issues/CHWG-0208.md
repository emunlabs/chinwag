# CHWG-0208 — CHWG-0208: Fix Top Header Navigation (CI/CD Sticky-Cookie Hijack, Docs target=_blank, docs.chinwag.sh 302 Removal & Single-Row Header Layout) + Mandatory Link-Destination QA Gate

Fixes top-header navigation across `chinwag.sh` and `docs.chinwag.sh`:
1. **CI/CD Sticky-Cookie Immunity (`/ci-cd`):** Eliminates root `/` sticky-cookie (`cw_ab_v2`) hijacking on top-header `CI/CD` links so clicking `CI/CD` always lands deterministically on `/ci-cd` (`ci-cd.html` / `index-cicd.html`) regardless of the visitor's cookie state.
2. **Docs Link & Canonical Redirects (`docs.chinwag.sh` / `doc.chinwag.sh`):** Opens external `https://docs.chinwag.sh` header links in a new tab (`target="_blank" rel="noopener"`), removes unnecessary `302` redirects on `docs.chinwag.sh`, and enforces a `301` redirect from `https://doc.chinwag.sh/*` to `https://docs.chinwag.sh/*` at the edge proxy.
3. **Single-Row Desktop Header Layout & Mandatory Link-Destination QA Gate:** Guarantees single-row desktop header alignment (`1440×900`) and adds a mandatory Playwright link-destination verification gate (`■ QA`) asserting that every top-header nav link resolves to its canonical destination URL and document heading without sticky-cookie interference.
